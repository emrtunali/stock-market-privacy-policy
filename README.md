## 🚀 Quick Setup Steps

### Step 1: Create GitHub Repository
1. Go to [github.com/new](https://github.com/new)
2. Repository name: `stock-market-privacy-policy`
3. Description: `Privacy Policy for Stock Market App`
4. Select: **Public**
5. Click: **Create repository**

### Step 2: Push This Folder
Run these commands in terminal:

```bash
cd /Users/emirtunali/.gemini/antigravity/scratch/Stock-Market-Appvs2/privacy-policy

git init
git add .
git commit -m "Add privacy policy page"
git branch -M main
git remote add origin https://github.com/emirtunali/stock-market-privacy-policy.git
git push -u origin main
```

### Step 3: Enable GitHub Pages
1. Go to your repository on GitHub
2. Click **Settings** tab
3. Click **Pages** in the left sidebar
4. Under "Source", select **main** branch
5. Folder: **/ (root)**
6. Click **Save**

### Step 4: Wait & Access
- Wait 1-2 minutes for deployment
- Visit: `https://emirtunali.github.io/stock-market-privacy-policy/`
